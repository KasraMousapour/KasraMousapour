## 🌟 Featured Engineering Projects

### 🛍️ [Shopify — Full-Stack E-Commerce Platform](https://github.com/KasraMousapour/shopify)
> **A production-ready, full-stack e-commerce system built with modern monorepo architecture.**
- **Architecture:** Monorepo with separated **Storefront**, **Admin Dashboard**, and **FastAPI Backend Core**.
- **Storefront (Next.js 14 App Router):** Responsive modern UI, RTL Persian typography (Vazirmatn), optimistic cart drawer updates, multi-step checkout flow, and mock payment gateway verification.
- **Admin Dashboard (Vite + React + TypeScript + TanStack):** Comprehensive management portal for products, inventory variants, categories, real-time orders, and analytics using shadcn/ui.
- **Backend (FastAPI + SQLModel + PostgreSQL):** OAuth2 Password Bearer JWT authentication, transactional inventory reduction on purchase, automated Alembic migrations, and self-documenting OpenAPI specs.
- **DevOps:** End-to-end containerized setup orchestrated with **Docker Compose** including Mailpit email testing.

---

### 🎟️ [Ticketing System & QA Testing Suite](https://github.com/KasraMousapour/learning-software-testing)
> **High-concurrency event reservation system focusing on software quality, hexagonal architecture, and race-condition prevention.**
- **Hexagonal Architecture:** Strict layer decoupling between Domain Models, Repository Layer, Application Services, and FastAPI Controllers.
- **Concurrency & Race Conditions:** Atomic database transactions and seat allocation locking to eliminate overbooking under heavy load.
- **Comprehensive Testing (Pytest):**
  - **Unit Tests:** Fast, isolated business logic verification with dependency mocking.
  - **Integration Tests:** Database transactions with automatic rollback fixtures.
  - **API Tests:** End-to-end endpoint verification with real HTTP clients.
  - **Concurrency Tests:** Multi-threaded stress testing replicating simultaneous seat reservation requests.

### 🎬 [Movie Rating System](https://github.com/KasraMousapour/MovieRatingSystem)
> **Clean-architecture backend API for managing movie catalogs, directors, genres, and user ratings.**
- Built with **FastAPI**, **SQLAlchemy ORM**, **PostgreSQL**, and **Poetry**.
- Layered repository pattern with dependency injection for clean data access abstraction.
- Custom structured logging pipeline (`logging.conf`) for production observability and audit trails.
- Automated database schema migrations via Alembic and database seeding scripts.

### 🔗 [High-Performance URL Shortener](https://github.com/KasraMousapour/URLShortener)
> **Scalable URL shortening microservice with custom Base62 encoding and background expiration scheduling.**
- **Base62 Algorithm:** Efficient ID-to-Base62 encoding ensuring minimal collision probability and compact URLs.
- **TTL (Time-To-Live) Lifecycle:** Automated background scheduler running every 20 minutes to detect and purge expired URLs without blocking incoming API traffic.
- **Quality Assurance:** Full API test coverage with documented Postman collections covering 2xx success and 4xx error cases.
